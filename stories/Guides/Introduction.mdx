Bahasa desain untuk platform KarirLink — token warna, tipografi, ikon, dan pustaka
komponen yang konsisten, dibangun 100% dengan utility Tailwind CSS v4 (tanpa framework JS).

Gunakan sidebar di sebelah kiri untuk menjelajah:

- **Foundations** — Colors, Typography, Icons: token dasar yang menurunkan semua komponen.
- **Components** — satu komponen per halaman: Button, Button Group, Badge, Avatar, Card,
  Input, Search, Select, Datepicker, Timepicker, Textarea, Checkbox, Radio, Toggle, Dropdown,
  Modal, Sidebar, Tabs, Breadcrumb, Table, Alert, Toast, QR Code, WYSIWYG,
  Progress, Tooltip, Divider.

Setiap story menampilkan markup HTML + class Tailwind apa adanya, siap disalin ke halaman baru.
Story-story ini benar-benar interaktif (bukan sekadar tangkapan layar statis) — behavior script
yang sama dipakai `index.html` (`assets/js/table.js`, `modal.js`, `datepicker.js`, dst.) ikut dimuat
di Storybook lewat `.storybook/preview-head.html`.
